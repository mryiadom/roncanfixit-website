# Deploying to Cloudflare Pages

This guide will walk you through deploying your React/Vite website to Cloudflare Pages.

## Prerequisites
1.  A **GitHub Account** (https://github.com/).
2.  A **Cloudflare Account** (https://dash.cloudflare.com/).

## Step 1: Initialize Git and Push to GitHub
First, you need to put your code into a Git repository and push it to GitHub.

1.  **Initialize Git** (if you haven't already):
    Open your terminal in VS Code and run:
    ```bash
    git init
    git add .
    git commit -m "Initial commit"
    ```

2.  **Create a Repository on GitHub**:
    - Go to GitHub and click the **+** icon -> **New repository**.
    - Name it `roncanfixit-website`.
    - Do **not** check "Initialize with README".
    - Click **Create repository**.

3.  **Push your code**:
    - Copy the commands shown on GitHub under "…or push an existing repository from the command line". They will look like this:
    ```bash
    git remote add origin https://github.com/YOUR_USERNAME/roncanfixit-website.git
    git branch -M main
    git push -u origin main
    ```

## Step 2: Deploy on Cloudflare Pages
1.  Log in to the **Cloudflare Dashboard**.
2.  Go to **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3.  Select your GitHub account (you may need to authorize Cloudflare).
4.  Select the `roncanfixit-website` repository you just created.
5.  **Configure the build settings** (Cloudflare usually auto-detects these correctly):
    - **Project Name**: `roncanfixit`
    - **Production Branch**: `main`
    - **Framework Preset**: Select `Vite` (or `React`).
    - **Build Command**: `npm run build`
    - **Build Output Directory**: `dist`
6.  Click **Save and Deploy**.

Cloudflare will now build and deploy your site!

## Important Note About Reviews
Your reviews are loaded from `public/reviews.json`, which is generated by your Python script.
- The Python script **does not run on Cloudflare**.
- To update reviews, you must run the scraper locally (`python review_scraper.py`), commit the updated JSON file to Git, and push. Cloudflare will see the change and update the site.
